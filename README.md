# Consciousness Is Subjectivity

## Core claim

**If consciousness is subjectivity, then a definition of consciousness that removes subjectivity has removed the phenomenon it claims to define.**

Consciousness is commonly approached through observable mechanisms, correlates, behaviors, and conditions. Those can help describe or investigate consciousness, but they are not identical to the phenomenon of subjective experience itself.

This repository develops a narrower proposition: if subjectivity is constitutive of consciousness, then an adequate definition of consciousness must retain subjectivity rather than replace it with exclusively third-person variables.

## Central distinction

An objective account may study consciousness.

An objective account cannot define subjectivity *out of* consciousness and still claim to have preserved the same phenomenon.

## Repository structure

- [`definition.md`](definition.md) — statement of the conceptual claim
- [`equation.md`](equation.md) — formal illustration of a subject-indexed experiential variable

## Scope

This repository does **not** propose a biological mechanism of consciousness, a diagnostic test for consciousness, or a proof that any particular system is conscious.

The formalism is used only to illustrate the conceptual distinction between an externally specified condition and experience indexed to a subject.
