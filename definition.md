# Definition

**Consciousness is subjective experience.**

The critical component is **subjective**.

If the phenomenon itself is subjectivity, then consciousness must be defined in a way that preserves its subjective character.

An objective account may describe mechanisms, correlates, behaviors, or conditions associated with consciousness. But if subjectivity is removed from the definition, the phenomenon being defined has been removed with it.

This is not the claim that consciousness cannot be studied objectively. It is the narrower claim that an exclusively third-person description cannot substitute for the first-person phenomenon if that first-person character is constitutive of consciousness.
